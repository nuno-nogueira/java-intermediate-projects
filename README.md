# Java Intermediate Projects

A group of five small Java projects developed while studying intermediate Java concepts and application development.

The projects mainly focus on practicing **Object-Oriented Programming, collections, user input, exception handling, file management, randomization, APIs, and JSON parsing.**

## Projects

### 🎲 Dice Simulator

A console-based dice simulator that allows the user to choose how many dice to roll and displays the result of each roll using ASCII representations.

**Concepts practiced**:

- Loops and conditional logic;
- Exception Handling.

---

### 🎯 Word Guessing Game

A console-based word guessing game where the player attempts to discover a randomly selected word by guessing individual letters.

The player has a limited number of attempts based on the difficulty chosen. (Easy, Medium, Hard)

**Concepts practiced**

- Object-Oriented Programming;
- String Manipulation;
- Game state management;
- Encapsulation.

---

### 🔐 Password Generator

A customizable password generator that creates random passwords based on the character types selected by the user.

Users can choose to include lowercase letters, uppercase letters, numbers & special characters.

**Concepts Practiced**:

- String Manipulation;
- Conditional Logic.

---

### 📁 File Manager

A simple command-line file manager capable of interacting with files and directories on the local filesystem.

The application can:

- List files and directories;
- Create directories;
- Delete files or directories.

**Concepts practiced**:

- Java File I/O;
- Object-Oriented Programming;
- Methods and Classes;[]()
- Filesystem operations.

---

### 🌤️ Weather App

A console-based weather application that retrieves a weather forecast for a city using a weather API and parses the returned JSON response.

The application displays information such as date, temperature, humidity, and weather description.

**Concepts practiced**:

- HTTP/API requests;
- JSON parsing;
- External APIs;
- Date and time formatting.

--- 
### Purpose

These projects were created as practical exercises to strengthen Java programming fundamentals and gain experience building small, and independent applications.
